Coverage and budget
Coverage gaps

AI Voice Agent · ⚠️ Partial · ❌ Gap · ❌ Gap · ⚠️ Partial · ⚠️ Partial
Accepted gap: Fairness. We accept this gap because the agent only handles basic calls and any caller can reach a person. We’ll look again: We’ll look again if escalation or hang-up rates for any caller language or region run 5+ points above the overall rate, or at the next quarterly review.
Gap to close first: We’ve identified latency as the most critical gap for the AI Voice Agent. Users expect timely answers. If responses are slow, they’ll hang up and call a person instead. To close it, we’ll add a drift monitor on response time per call turn, alerting when p95 goes above 2 seconds over a rolling hour. We’ll also add a latency threshold to the release eval gate, blocking release if p95 on the 300-question set goes above 2 seconds. When the alert fires, the on-call engineer is paged.
